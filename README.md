# ✍️ Auto Text Effect Animation

Учебный пет-проект: анимация эффекта печатающегося текста (Auto Typing / Text Effect) для динамической смены профессий/ролей.

## ⚒️ Стек технологий

- **HTML5** — семантическая разметка
- **CSS3 / SCSS** — стилизация приложения и подключение кастомных шрифтов
- **Vanilla JS (ES6+)** — логика посимвольного вывода текста, смены элементов и работы с `setTimeout`

## 📌 Функционал приложения

- [] Автоматический посимвольный вывод текста (эффект печати)
- [x] Динамическая подстановка неопределенного артикля (`a` / `an`) в зависимости от первой буквы слова
- [x] Бесконечный цикл переключения между несколькими профессиями/ролями
- [x] Динамическое обновление DOM-дерева через JavaScript
